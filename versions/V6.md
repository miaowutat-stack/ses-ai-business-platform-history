## 目指す方向と現在地

V4の案件条件、技術者の経歴、提案・結果履歴等を基盤に、面談で得た詳細な情報と営業接点の記録を整理します。技術者・営業・顧客などの視点、出典、事実と所感を区別し、人が確認して営業判断に利用できる形にすることを目指しています。

V6では、技術者・営業の追問対話、客先資料の作成者区分、根拠付き草案、照合、総合報告と人による項目別レビューを隔離環境で実装・検証しています。すべての分析役割が独立したエージェントとして完成したという意味ではありません。

|---|---|
| 実装した範囲 | 面談報告、追問、出典付きAI草案、採用・修正・保留、同意と情報の版の確認、役割に応じた操作 |
| 失敗と修正 | 一時的なメモリ不足によるブラウザ確認保留、その後の受入確認、独立QAでの表示・出典・権限・個人情報保護の指摘と是正をすべて収録 |

| 最新修正の状態 | 最終コミットe6824f5には関連自動テストの記録があるが、修正後の独立QA・ブラウザ・実モデルを含む一連の再検証は未完了 |
| 未統合の範囲 | 共用環境への統合、業務ナレッジの長期記憶への登録は未完了。V6の情報は原情報として扱い、V4のBusiness Memoryや検索基盤へ自動登録しない |
